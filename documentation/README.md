# Documentation

Store and maintain the project's user and developer documentation in this directory.

## Documentation guidelines

- Update existing pages when documenting a change; create a new page only when it adds a distinct, useful topic.
- Describe behavior that is present in the implementation and use examples that match the current code.
- Link related topics and avoid duplicating information that already has a clear source of truth.
- Include prerequisites, configuration, usage, limitations, and validation guidance where relevant.
- Keep pages concise, structured, and current as features change.
